# Linkwave Technology

Official website of Linkwave Technology.

Website: https://linkwave.tech

Static HTML/CSS/JavaScript served by GitHub Pages. No build step, no backend, no
third-party JavaScript and no cookies or trackers.

- English: `https://linkwave.tech/`
- Arabic: `https://linkwave.tech/ar/`
- Every page has a stable `lang`/`dir` and matching `hreflang`/canonical metadata.
- Contact details and the enquiry endpoint are configured in `js/site-config.js`.
- Third-party notices: `THIRD-PARTY-NOTICES.txt`.
